개인정보처리방침

LSG Studio는 유튜브 채널 연결과 영상 예약 게시를 위해 YouTube API Services를 사용합니다. Google이 직접 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다.

접근과 사용

Google에서 승인을 받으면 채널 ID·이름·핸들과 인증 토큰을 받습니다. 채널 정보는 선택한 채널을 표시하고 예약과 실제 전송 계정이 일치하는지 확인하는 데 쓰입니다. 토큰은 Google API에 요청을 보내고 연결을 갱신하는 데 쓰입니다. 계정 비밀번호는 Google 로그인 화면에서 직접 입력합니다.

예약 시간이 되면 운영자가 확정한 영상·썸네일·제목·설명·태그·공개 설정을 YouTube로 전송합니다. YouTube가 돌려준 영상 ID, 게시 주소와 처리 상태는 예약 내역을 표시하고 전송 결과를 확인하는 데 쓰입니다.

저장과 공유

채널 연결 정보와 토큰은 Studio 서버에 저장합니다. 예약 문구, 확정 파일, 게시 기록도 운영자가 예약을 관리할 수 있도록 Studio 서버에 저장합니다. 작업실은 브라우저 저장소를 사용해 편집 화면 선택을 기억하고, 원격 접속이 설정된 경우 접속 확인용 쿠키를 사용합니다.

Studio가 승인받은 Google 데이터는 채널 확인과 예약 게시에 사용합니다. 이 데이터는 광고나 판매에 쓰이지 않습니다. 게시 콘텐츠는 운영자가 선택한 공개 범위에 따라 YouTube에서 열람할 수 있습니다.

연결 해제와 데이터 삭제

Studio의 설정 → YouTube 계정 연결 → 연결 삭제에서 로컬 연결 정보를 제거할 수 있습니다. Google 계정의 연결된 앱 설정에서 Google에 부여한 권한도 취소할 수 있습니다. 예약 기록에 남은 YouTube 데이터를 지우려면 Studio 운영자에게 삭제를 요청할 수 있습니다. 이미 올라간 영상은 YouTube Studio에서 관리합니다.
